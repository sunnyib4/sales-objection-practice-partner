What is this
What is Pushback?

A voice-based practice partner built on AssemblyAI's Voice Agent API. It plays a skeptical prospect who tags each objection it raises via tool-calling, then hands off the transcript to AssemblyAI's LLM Gateway to generate an honest, category-scored review of the call.
